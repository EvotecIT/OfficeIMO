# Standalone WebApplicationV1 fixture

This first-party, offline application is the representative acceptance fixture for
the owned `WebApplicationV1` contract. It combines static module imports, fetch,
handled HTTP failure, live CSS with `@import`, mutation delivery, storage, forms,
cross-document navigation, unload lifecycle, history traversal, layout-aware input,
locator rebinding and independent capture.

Passing the fixture proves this bounded workflow with the documented profile. It
does not establish general framework, browser, JavaScript or hostile-content
compatibility.
