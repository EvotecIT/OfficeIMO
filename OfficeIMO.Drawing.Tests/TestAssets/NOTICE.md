# OpenSans-Regular.woff2

`OpenSans-Regular.woff2` is an OFL-1.1 test font retained by the SixLabors.Fonts
project:

- Fixture source: https://github.com/SixLabors/Fonts/blob/v2.1.3/tests/SixLabors.Fonts.Tests/Fonts/OpenSans-Regular.woff2
- Source family: https://github.com/google/fonts/tree/main/ofl/opensans
- License: SIL Open Font License 1.1

The fixture is retained only for font-container, measurement, shaping, and
outline-rendering tests.

Copyright 2020 The Open Sans Project Authors (https://github.com/googlefonts/opensans)
