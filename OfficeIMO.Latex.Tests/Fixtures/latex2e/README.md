# LaTeX Project input fixtures

`small2e.tex` and `sample2e.tex` are unchanged samples from the LaTeX Project's
[latex2e source](https://github.com/latex3/latex2e/tree/f4c052f4fb91b4dd616dff60280da3c5d5aea89c/base)
at revision `f4c052f4fb91b4dd616dff60280da3c5d5aea89c`. They provide independent
input for source preservation, paragraph ownership, formatting, nested lists,
quotations and footnote conversion tests. OfficeIMO did not generate these inputs.

This fixture selection is a partial redistribution of the LaTeX base work under
LPPL 1.3c or later. The included components have no content changes; only their
placement in this test directory differs from the upstream distribution.
`legal.txt` and `lppl.txt` contain the original copyright and license notices.
A complete, unchanged copy of the original work can be obtained from the
[pinned source archive](https://github.com/latex3/latex2e/archive/f4c052f4fb91b4dd616dff60280da3c5d5aea89c.tar.gz).
The original authors do not provide support for OfficeIMO or this test selection.

The tests verify the original SHA-256 values. These files stay outside production
packages. Passing these samples qualifies their tested structures; it does not
establish support for every LaTeX command, package or typesetting behavior.
