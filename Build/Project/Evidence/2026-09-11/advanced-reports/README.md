# Advanced calculation and report evidence

This evidence captures the declared Project calculation/report profiles on Windows and Ubuntu WSL. `validation.json` records the tested runtimes, local package consumer, review disposition, and the unrelated workflow-suite failure reproduced on the unchanged base. `local-packages.json` identifies the unsigned local package artifacts used by that consumer; no public release is implied.

Application readback JSON retains selected task/assignment/lookup semantics and source hashes for authored/edited outlines, custom fields, rollups, and multi-assignment interruptions. The corresponding executable cases live in `OfficeIMO.Project.Verification`; the committed producer fixture manifest supplies independent inputs.

`report-pages.json` records portable pagination for all layouts and the 75-task cases. The three images show the corrected terminal milestone, the final native PowerPoint dependency page, and Excel's printed date/time values. Microsoft Office readback establishes the sampled native report behavior, not arbitrary fonts, printer drivers, or native Project view fidelity.
