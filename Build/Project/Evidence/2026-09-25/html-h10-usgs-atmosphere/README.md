# H10 USGS atmosphere article: acquisition-blocked selection

The [H10 selection manifest](../../../../../OfficeIMO.Pdf.Benchmarks.Comparisons/Corpus/html-h10-page-selection.json) predeclared [The Atmosphere and the Water Cycle](https://www.usgs.gov/water-science-school/science/atmosphere-and-water-cycle) as a replacement held-out page on 2026-09-25. Selection used the published source only, before OfficeIMO capture, rendering or conversion. The page has long explanatory prose, an attributed image, related links and a numeric data table.

The declared Chromium MHTML acquisition at clean source `fc310a9c1` failed with HTTP 403 during navigation, before an archive or browser reference was created. A direct HTTP fetch returned 403 too. No OfficeIMO conversion was attempted, so this page supplies no held-out qualification evidence. Substituting a different acquisition route would change the declared capture contract. The independently selected [CDC drinking-water article](../html-h10-cdc-drinking-water/README.md) is the replacement.

The predeclared source markers and editable-target criteria remain in the manifest as a record of what was selected before acquisition failed. They were not tested. The H10 PDF, editable-output and platform-budget criteria remain open for the replacement case.

The [USGS copyright guidance](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits) says USGS-produced information is generally in the U.S. public domain while some third-party imagery is not. The page credits an image to Wikimedia/Creative Commons; its specific reuse terms need verification before that image appears in checked-in visual evidence. The source page and credit remain linked so the local capture can be audited.
