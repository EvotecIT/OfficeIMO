The exact PDFs, reports and all-page PNGs are retained in the ignored local probe directory named above. This is a preservation gap; matching the screen-media page count does not close it.

The two prominent footer images are present in the MHTML archive but cannot be embedded in the managed PDF. The screen-media report contains two `HtmlPdfImagePayloadOmitted` warnings, and the corrected screen snapshot contains four fragment-level warnings for those two assets. Both also report 85 unsupported SVG-content observations and 26 unavailable font faces. After fragment removal and resolution against the captured page URL, none of the 110 unique screen-snapshot `HtmlRenderResourceUnavailable` sources matched the archive's 46 Content-Location entries; those observations are capture omissions, not further CID lookup failures. The present-but-undecodable WebP assets and SVG/typography observations are separate renderer gaps. Qualifying either screen intent requires remediation or explicit bounded exclusions; page counts and selected text alone are insufficient.
