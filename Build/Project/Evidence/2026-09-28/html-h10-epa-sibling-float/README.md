An exploratory trace then narrowed the boundary. The archived box is inside `div.l-sidebar--reversed`, which the captured print CSS renders as flex. Top-level deferred-float relayout was attempted eight times for blocks containing that box, but none deferred it. The box's inline float run received no page boundary in those attempts: flex-item layout calls `LayoutElement` without propagating that boundary. The compact trace is retained at `Ignore/HtmlUnknownPageQualification/h10-epa-float-trace/float.trace`; its temporary diagnostic logging is absent from the committed source.

The next EPA change should qualify flex-item pagination and float-boundary propagation with a focused regression, then replay the archive. This trace identifies a reachable barrier to the sibling fix; it does not prove that removing the barrier alone will match Chromium.
