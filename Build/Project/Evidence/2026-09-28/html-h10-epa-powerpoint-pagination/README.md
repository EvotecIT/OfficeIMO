# EPA editable PowerPoint table pagination

At clean source `5a0d920122ddbd32c32381b8eb4067a0d809a495`, the frozen EPA MHTML archive (`12ac44c94520a28c5797c1c764df47ecb833db932e2772be868a25e9b7062dc3`) was replayed into an editable PowerPoint presentation. The preceding projection used per-cell text boxes and spread the regulatory table across a 20-slide presentation. The generic HTML adapter now partitions an eligible tall table into native row-group tables, repeats its header on continuation slides, and records an approximation. Unsupported vertical row spans or a row too tall for a slide retain the reported fallback.

The saved presentation reopens and has 11 slides. Package inspection finds exactly two native table shapes, on slides 5 and 6. LibreOffice's independent PDF export also has 11 pages; visual inspection of both table pages shows the caption with the first header and data rows, a repeated header on page 6, and no visible clipping.
