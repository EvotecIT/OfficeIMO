# Cropped inline picture fixture

Microsoft Word 16.0 on Windows produced this Word 97–2003 document. It contains
one Aptos 12-point text paragraph and one inline picture from the repository's
`Images/Kulek.jpg` asset. Its serialized source crop removes approximately
7.617 percent from each horizontal side and 3.047 percent from the top. The
displayed frame is 144 by 72 points.

The fixture protects independent-producer import, default font resolution,
source crop preservation, and optimized native DOC saving. Production code does
not use Word or COM.
