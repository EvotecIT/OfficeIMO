The Managed Document Handbook

A practical long-form sample for searchable, paged HTML output.

Chapter 1 · Stable inputs

Document systems become predictable when source identity, resources, layout intent and output intent are recorded before rendering begins.

A static screen snapshot and a print layout can share content while producing different geometry. The caller chooses that contract explicitly.

Keep the source immutable while one render request is in flight.

References remain useful only when the exact HTML, fonts, media context and page settings travel with the evidence.

Long-form content also tests column flow, paragraph spacing, headings and reading order without relying on a browser process.

Chapter 2 · Fragmentation

Pages preserve logical text while placing visual fragments independently.

Headings should remain with the content they introduce. Tables may repeat their headers, while rows marked to avoid breaks move as a unit when space permits.

Named pages select geometry for a complete page context. Running content belongs to the page decoration layer rather than the body flow.

Footnote calls remain in reading orderHandbook note: footnote text is retained as searchable content and placed in the page footnote area. even when the note itself moves to the page boundary.

The renderer reports unsupported requests instead of silently presenting a lower-fidelity result as complete.
