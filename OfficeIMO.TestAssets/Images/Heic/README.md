# HEIC still-image fixtures

The public test charts come from [heic.fyi](https://heic.fyi/heic-sample-files), under [CC0 1.0](LICENSE-CC0.txt). `sources.json` records the original URLs, byte lengths and SHA-256 hashes. The eight files total about 1.6 MB and cover a single item, a 48-tile grid, mirroring, both quarter-turn rotations, 10-bit Display P3 with ICC, alpha and the generic `mif1` brand. The charts contain no personal photographs or GPS locations.

I compare these files against the operating system's full-file decode. No third-party decoded previews, reference pixels, generation scripts or decoder libraries are used. Compressed fixture data is not a redistributed decoder.

Small grid, crop, orientation, EXIF precedence and alpha cases are generated by `OfficeIMO.TestAssets/HeicTestFixture.cs`. Their one-byte sample payloads are consumed only by the fake codec in managed composition tests; they are not valid HEVC streams.

`RealPhotos` is the slot for camera photographs. See its README before adding files. Platform tests also accept an external directory through `OFFICEIMO_HEIC_REAL_PHOTOS`.
