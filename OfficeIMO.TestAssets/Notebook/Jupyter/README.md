# Jupyter reference notebooks

These unmodified notebooks come from the `tests` directory in the [nbformat v5.11.1 source](https://github.com/jupyter/nbformat/tree/75f819f5b60bc6ffc72145c364132efe5b3c4b35/tests). The [fixture inventory](fixtures.json) records their SHA-256 digests. Redistribution is under the accompanying [BSD 3-Clause license](LICENSE).

- `test3.ipynb` exercises the legacy worksheet-based shape.
- `test4.5.ipynb` contains cell IDs, a stored plot, stream output, and HTML and JavaScript MIME alternatives.
- `test4plus.ipynb` adds a future minor version, extension fields, an unknown cell kind and an unknown output kind.
- `test4custom.ipynb` carries a vendor JSON MIME payload.
- `many_tracebacks.ipynb` carries saved traceback lines.
