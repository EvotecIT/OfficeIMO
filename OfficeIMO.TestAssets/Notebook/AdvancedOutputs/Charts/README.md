# Plotly saved-output fixtures

`plotly-advanced.ipynb` was generated by Plotly.py's notebook MIME renderer. It contains a marker-only 3D helix, a gridded 3D surface with an authored orthographic camera and axis labels, and a 2D WebGL scatter. The notebook stores only the Plotly figure specifications. NumPy coordinates use Plotly's binary typed arrays, including a rank-two surface.

The helix adapts the **Basic 3D Scatter Plot** recipe in the [Plotly.py Jupytext notebook](https://github.com/plotly/plotly.py/blob/495134a8c74406a85660ae56178049017e0e3a41/doc/python/3d-scatter-plots.md). Its [MIT notice](LICENSE.plotly-py.txt) is included. The surface and WebGL scatter recipes are original to this fixture. The generator uses deterministic data and pins the producer packages in [requirements.txt](requirements.txt).

`plotly-interactive.ipynb` contains five executed chart recipes from an illustrative river sampling survey. The [generator](generate_interactive.py) runs the checked-in cell source and saves each figure with Plotly.py's `plotly_mimetype` renderer. The notebook stores JSON specifications without rendered images or embedded JavaScript. Its sample readings and inline region boundaries were authored for this fixture.

| Cell ID | Saved figure |
| --- | --- |
| `survey-mesh` | Nine sampled positions, eight explicit triangular faces, and a saved perspective camera |
| `survey-route` | Lower Hudson River coordinates with connected survey stops in an equirectangular view |
| `survey-regions` | Three inline GeoJSON sampling regions colored by sample count |
| `station-heatmap` | A typed `3 × 4` matrix with one missing reading. The value at hour `2` and depth `25` is `18.5`. |
| `station-subplots` | Two panels from `make_subplots`, with independent titled axes, a connected scatter, and grouped bars |
