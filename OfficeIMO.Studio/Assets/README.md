# OfficeIMO Studio identity

`OfficeIMO.Studio.svg` is the editable source for the Studio application icon. It adapts the current OfficeIMO website mark—a document sheet with a cyan companion spine—into a full-bleed native application tile. `OfficeIMO.Studio.png` and `OfficeIMO.Studio.ico` are generated exports used by packaging and Windows application metadata.

Keep the mark free of text so it remains legible at launcher and taskbar sizes. Platform packaging may apply its own mask; do not pre-render a circular crop or replace the OfficeIMO product identity with the Evotec corporate mark.
