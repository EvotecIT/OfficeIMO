# Browser notebook fonts

STIX Two Math 2.13 b171 is distributed under the [SIL Open Font License](Assets/OFL-STIX.txt).
The [unchanged TrueType font](https://github.com/stipub/stixfonts/blob/744a22a4dd626cd14d75728aef34fc8ad7c85db0/fonts/static_ttf/STIXTwoMath-Regular.ttf)
is loaded by the Jupyter PDF browser tool. The website engine publishes its
license alongside the existing font notices.

The browser embeds the [Liberation Mono 2.1.5](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5)
regular face for code and text output. The unchanged TrueType font is from
the upstream release archive and carries its [SIL Open Font License](Assets/OFL-Liberation.txt).
