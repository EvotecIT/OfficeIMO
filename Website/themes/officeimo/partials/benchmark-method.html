What a published result means

  • Same work, checked output. Every library processes the same input, and its output is validated before it is timed.
  • Enough samples. At least 3 warmups and 10 measured samples per case, with a 95% confidence interval for the median.
  • Even when it is close. When two confidence intervals overlap, the libraries are shown as even, not as faster or slower.
  • Every case stays. Cases another library wins, failed cases and partial runs are kept with their reason.
  • Traceable runs. Each run records a clean source commit, the operating system, CPU, runtime and SDK, and the exact version and hash of every compared package.
  • Licences respected. Libraries whose licence does not allow publishing results are run only locally and shown as not published.

Platforms are measured separately and never averaged together. Measure on hardware close to yours before deciding.
