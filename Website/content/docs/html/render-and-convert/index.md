There are two ways to turn HTML into something else. Visual rendering keeps the page's appearance: `OfficeIMO.Html.Pdf` lays the page out and paints it into images (or PDF). Semantic conversion keeps the page's structure: `OfficeIMO.Word.Html`, `OfficeIMO.Markdown.Html` and `OfficeIMO.Html.Rtf` map headings, paragraphs, lists, links and tables into editable content. Choose rendering when the picture is the contract, and semantic conversion when someone will keep editing the result.

## Render HTML to a PNG or SVG image

`ToImage` returns one image; `SaveAsImage` writes it. `Mode = HtmlRenderMode.Continuous` captures one long screenshot instead of paged output.

### C#

```csharp
using OfficeIMO.Drawing;
using OfficeIMO.Html;
using OfficeIMO.Html.Pdf;

HtmlConversionDocument source = HtmlConversionDocument.Parse(
    "<h1>Status</h1><p>Generated by OfficeIMO.</p>");

var options = new HtmlRenderOptions {
    ViewportWidth = 720,
    Mode = HtmlRenderMode.Continuous,
    Margins = HtmlRenderMargins.All(24),
    Scale = 1.5,
    Format = OfficeImageExportFormat.Png
};
options.AdditionalStylesheets.Add("body { font-family: Arial; color: #223 }");

byte[] png = source.ToImage(options).Bytes;
File.WriteAllBytes("status.png", png);

string svg = source.ToSvg(options);
File.WriteAllText("status.svg", svg);
```

### PowerShell

```powershell
Export-OfficeDocumentImage -Text '<h1>Service status</h1><p>All green.</p>' -From Html -OutputPath .\status.png
```

### CLI

The `render` command writes images into a ZIP archive with a manifest:

```sh
officeimo html render status.html --profile screen-full-page --encoder png --viewport-width 720 --output status-images.zip
```

## Save every page as an image

Paged mode (the default) breaks the document into sheets the same way PDF output does. `SaveAsImages` writes one file per page into a folder.

### C#

```csharp
using OfficeIMO;
using OfficeIMO.Drawing;
using OfficeIMO.Html;
using OfficeIMO.Html.Pdf;

string html = string.Concat(Enumerable.Range(1, 40).Select(i => $"<p>Line {i} of the report.</p>"));
HtmlConversionDocument source = HtmlConversionDocument.Parse("<h1>Report</h1>" + html);

var options = new HtmlRenderOptions {
    Mode = HtmlRenderMode.Paged,
    PageSize = OfficePageSizes.A4,
    Format = OfficeImageExportFormat.Webp,
    MaxPageCount = 20
};

OfficeConversionReport report = source.SaveAsImages("report-pages", options);
Console.WriteLine($"{report.ItemsWritten} pages written");
```

### PowerShell

```powershell
$render = New-OfficeHtmlRenderOptions -ViewportWidth 1280 -MaxPageCount 10
Export-OfficeDocumentImage -Text (Get-Content .\Report.html -Raw) -From Html -OutputDirectory .\pages -Format Png -Options $render
```

### CLI

```sh
officeimo html render report.html --profile print-paged --pages all --output report-pages.zip
```

## Stop when the render would lose content

By default unsupported CSS is approximated and reported. With `FailOnLoss`, a diagnosed simplification throws instead of producing an image.

### C#

```csharp
using OfficeIMO;
using OfficeIMO.Drawing;
using OfficeIMO.Html;
using OfficeIMO.Html.Pdf;

HtmlConversionDocument source = HtmlConversionDocument.Parse("<h1>Status</h1>");

var options = new HtmlRenderOptions {
    ViewportWidth = 720,
    FidelityPolicy = HtmlRenderFidelityPolicy.FailOnLoss,
    Format = OfficeImageExportFormat.Png
};

OfficeImageExportResult image = source.ToImage(options);
foreach (var diagnostic in image.Diagnostics) {
    Console.WriteLine($"{diagnostic.Code}: {diagnostic.Message}");
}
File.WriteAllBytes("status.png", image.Bytes);
```

## Convert HTML to Word

`ToWord` produces native Word headings, lists, tables, links and images, so the result stays editable.

### C#

```csharp
using OfficeIMO;
using OfficeIMO.Html;
using OfficeIMO.Word;
using OfficeIMO.Word.Html;

HtmlConversionDocument source = HtmlConversionDocument.Parse("""
<h1>Meeting notes</h1>
<ul><li>Budget approved</li><li>Launch moved to May</li></ul>
<table><tr><th>Owner</th><th>Task</th></tr><tr><td>Ana</td><td>Draft plan</td></tr></table>
""");

using WordDocument document = source.ToWord(new HtmlWordExportOptions(), out OfficeConversionReport report);
document.Save("meeting-notes.docx");

foreach (OfficeDiagnostic diagnostic in report.Diagnostics) {
    Console.WriteLine($"{diagnostic.Code}: {diagnostic.Message}");
}
```

### PowerShell

```powershell
$options = New-OfficeHtmlWordOptions -StylesheetPath .\report.css -RenderPreAsTable
Convert-OfficeDocument -Path .\Report.html -To Word -OutputPath .\Report.docx -Options $options
```

### CLI

```sh
officeimo convert Report.html Report.docx
```

## Convert HTML to RTF

The RTF bridge maps HTML into an editable `RtfDocument`. Positioned regions become RTF frames; anything without an RTF equivalent is reported.

### C#

```csharp
using OfficeIMO.Html;
using OfficeIMO.Rtf;

HtmlConversionDocument html = HtmlConversionDocument.Parse(
    "<p>Hello <strong>RTF</strong></p><ol><li>First</li><li>Second</li></ol>");

RtfDocument rtf = html.ToRtf();
File.WriteAllText("hello.rtf", rtf.ToRtf());
```

## Convert HTML to Markdown

See [Convert Markdown to HTML, PDF and Word](/docs/markdown/convert/#convert-html-to-markdown) for the profiles and cleanup options.

### C#

```csharp
using OfficeIMO.Html;
using OfficeIMO.Markdown;
using OfficeIMO.Markdown.Html;

using MarkdownDocument markdown = HtmlConversionDocument
    .Parse("<h1>Hello</h1><p>Body with <em>emphasis</em>.</p>")
    .ToMarkdown();

Console.WriteLine(markdown.ToMarkdown());
```

### CLI

```sh
officeimo convert page.html page.md
```
