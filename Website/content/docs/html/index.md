`OfficeIMO.Html` parses HTML into an `HtmlConversionDocument` with bounded limits, URL policy and base-URI handling. That one parsed document feeds every destination adapter, so Word, Markdown, RTF, PDF and image output agree on how the page was read. Install only the adapter for your destination:

| Destination | Package | Call |
|---|---|---|
| PDF and images (PNG, JPEG, TIFF, WebP, SVG) | `OfficeIMO.Html.Pdf` | `SaveAsPdf`, `ToImage`, `SaveAsImages` |
| Word | `OfficeIMO.Word.Html` | `ToWord` |
| Markdown | `OfficeIMO.Markdown.Html` | `ToMarkdown` |
| RTF | `OfficeIMO.Html.Rtf` | `ToRtf` |
| MHTML archives | `OfficeIMO.Mhtml` | `MhtmlDocument.Load` |
| Search and ingestion | `OfficeIMO.Reader.Html` | Reader handlers |

```sh
dotnet add package OfficeIMO.Html.Pdf
```

## Parse HTML from a string or file

Untrusted input is the default: no local file or network reads, and strict size and depth limits. Mark input as trusted only for your own templates.

### C#

```csharp
using OfficeIMO.Html;

HtmlConversionDocument fromText = HtmlConversionDocument.Parse(
    "<h1>Status</h1><p>Generated by OfficeIMO.</p>");
Console.WriteLine(fromText.NormalizedHtml);

File.WriteAllText("report.html", "<html><body><h1>Report</h1></body></html>");
HtmlConversionDocument fromFile = HtmlConversionDocument.Load("report.html", new HtmlConversionDocumentOptions {
    Trust = HtmlInputTrust.Trusted,
    BaseUri = new Uri(Path.GetFullPath(".") + Path.DirectorySeparatorChar)
});
Console.WriteLine(fromFile.SourceHtml.Length);
```

### PowerShell

```powershell
$document = New-OfficeHtmlConversionOptions -BaseUri (Resolve-Path .\Assets) -NoBodyContentsOnly
Convert-OfficeDocument -Path .\Report.html -To Word -OutputPath .\Report.docx -Options $document
```

## Convert HTML to PDF

### C#

```csharp
using OfficeIMO.Html;
using OfficeIMO.Html.Pdf;

HtmlConversionDocument
    .Parse("<h1>Status</h1><p>All systems normal.</p>")
    .SaveAsPdf("status.pdf");
```

### PowerShell

```powershell
Convert-OfficeDocument -Path .\Report.html -OutputPath .\Report.pdf
```

### CLI

```sh
officeimo html convert report.html --output report.pdf
```
