## How to read this page

A name in a cell is a package, command, MCP tool or Studio feature that does the job, linked to its guide or reference page. The page is generated from the package catalog, the PSWriteOffice command list, the AI agents page, the format map and the Studio feature matrix, so a renamed or removed capability can't stay listed here.

Browser tools that convert files in your tab without uploading them are listed on [Convert in your browser](/convert/). Supported formats and known limits for each conversion are in [format support](/compatibility/).
