All 2,160 measured outputs pass validation. Every allocation budget and every
note median/P95 budget passes, but ordinary Word 6 documents fail six latency
checks in three comparison groups. Performance qualification remains open.

108 per-domain metric comparisons, 144 launch summaries and 2,160 raw numerical
observations, including the failed checks and every early measured call.

## Equivalent work and method

The [workload contract](../../OfficeIMO.Migration.Benchmarks/README.md) defines
the three synthetic profiles. `Word69` contains one ASCII paragraph with
100/1,000/10,000 alternating bold runs and two shared character-property records.
`Word69Notes` uses FIB101 and `Word95Notes` FIB104, each with 10/100/1,000
alternating automatic footnotes/endnotes and two paragraphs per note.

`LoadInspect` includes public load and inspection. `ConvertSave` includes public
load and ordinary DOCX serialization into memory. Input generation, expected
values and validation are outside timing. Ordinary-document validation checks
every ordered run, text and bold flag, source format and loss diagnostics;
saved output is schema-validated and reopened. Its SemanticDigest is empty and
is not used as equality evidence. Note validation checks every body reference
and position, both note kinds, complete ordered paragraph text, numbering,
placement, note parts and reference identities, plus saved schema and public
reopen. A reader that omits notes fails this contract and is not an equivalent
note-performance reference.

The matrix has 16 fresh processes in reference, candidate, candidate, reference
order for each pair/domain. Each launch uses rotated case ordering, three
warmups, 15 measured iterations, Normal priority, `BeforeIteration` memory
cleanup and no outlier removal. Warmups skip measured-result validation and
metrics; that schedule is identical for both readers and remains unchanged.
The 720 ordinary-document and 1,440 note observations yield 30 samples per
reader/cell/domain. Shared PowerForge summaries, comparisons and budgets supply
the numbers; publication only selects fields from those existing results.

The Windows 11 Pro build 26300 host has an AMD Ryzen 9 9950X3D2, 16 cores/32
logical processors, firmware 3702 and the High performance power plan. Native
L3 domains use separate masks `0xFFFF` and `0xFFFF0000`. Measurement runs in
PowerShell 7.6.9 on .NET 10.0.14 with PSPublishModule/PowerForge 3.0.189; builds
use SDK 10.0.403. Runtime defaults are unchanged, including tiered compilation.
This is an ordinary-workstation comparison without an exclusive-host claim.

does not establish portable absolute timings. Independent qualification of a
genuine original FIB104/Word95 endnote document remains planned work. The six
ordinary-document latency failures remain unresolved performance criteria.
