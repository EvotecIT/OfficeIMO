# OPML fixture provenance

The small OPML documents in `OpmlDocumentTests` are repository-authored XML fixtures derived from the public [OPML 2.0 specification](https://opml.org/spec2.opml). They cover 1.0/1.1 profile selection, 2.0 outlines, RSS subscriptions, links, nesting, qualified extension attributes/elements, comments, malformed requirements, DTD rejection, and resource limits.

No third-party fixture bytes are redistributed. Output evidence uses create, write, reopen, semantic assertions, byte-exact unchanged-source assertions, and Reader ingestion. Add independently produced files here when a producer-specific behavior becomes part of the compatibility contract, recording the producer, version, date, source, license, and stable hash.
