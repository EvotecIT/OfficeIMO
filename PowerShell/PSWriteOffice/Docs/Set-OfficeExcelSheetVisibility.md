# Set-OfficeExcelSheetVisibility
## SYNOPSIS
Shows or hides a worksheet.

## SYNTAX
### Context (Default)
```powershell
Set-OfficeExcelSheetVisibility [-Show] [-Hide] [-PassThru] [<CommonParameters>]
```

### Document
```powershell
Set-OfficeExcelSheetVisibility -Document <ExcelDocument> [-Sheet <string>] [-SheetIndex <Int32>] [-Show] [-Hide] [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Shows or hides a worksheet.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> ExcelSheet 'Data' { Set-OfficeExcelSheetVisibility -Hide }
```

Marks the sheet as hidden.
