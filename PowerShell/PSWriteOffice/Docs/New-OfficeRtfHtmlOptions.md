# New-OfficeRtfHtmlOptions
## SYNOPSIS
Creates native WordHtmlExportOptions settings for document operations.

## SYNTAX
### Default (Default)
```powershell
New-OfficeRtfHtmlOptions [-Font <string>] [-IncludeFontStyles] [-IncludeListStyles] [-IncludeParagraphClasses] [-IncludeRunClasses] [-IncludeDefaultCss] [-UseImagePaths] [<CommonParameters>]
```

## DESCRIPTION
Creates native WordHtmlExportOptions settings for document operations.

## EXAMPLES

### EXAMPLE 1
```powershell
$options = New-OfficeRtfHtmlOptions
```
