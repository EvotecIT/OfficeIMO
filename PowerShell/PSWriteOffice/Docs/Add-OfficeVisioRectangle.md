# Add-OfficeVisioRectangle
## SYNOPSIS
Adds a rectangle shape to the current Visio page.

## SYNTAX
### __AllParameterSets
```powershell
Add-OfficeVisioRectangle [[-Text] <string>] [-Page <VisioPage>] [-Key <string>] [-X <double>] [-Y <double>] [-Width <double>] [-Height <double>] [-Unit <VisioMeasurementUnit>] [-Name <string>] [-NameU <string>] [-FillColor <string>] [-LineColor <string>] [-LineWeight <Double>] [-LinePattern <Int32>] [-FillPattern <Int32>] [-Angle <Double>] [-PassThru] [<CommonParameters>]
```

## DESCRIPTION
Adds a rectangle shape to the current Visio page.

## EXAMPLES

### EXAMPLE 1
```powershell
PS> OfficeVisio -Path .\Flow.vsdx {
    VisioRectangle -Key intake -Text 'Intake' -X 1.5 -Y 4 -Width 1.7 -Height 0.8 -FillColor '#E0F2FE'
}
```

Adds a rectangle and registers a key for later connector commands.
