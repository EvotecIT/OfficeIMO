# New-OfficeInvoiceParty
## SYNOPSIS
Creates a seller or buyer from ordinary party and address parameters.

## SYNTAX
### __AllParameterSets
```powershell
New-OfficeInvoiceParty [-Name] <string> -CountryCode <string> [-VatId <string>] [-AddressLine <string>] [-City <string>] [-PostCode <string>] [<CommonParameters>]
```

## DESCRIPTION
Creates a seller or buyer from ordinary party and address parameters.

## EXAMPLES

### EXAMPLE 1
```powershell
$seller = New-OfficeInvoiceParty -Name Example -CountryCode DE -VatId DE123456789
```
