## Windows-1257 mapping data

The Windows-1257 table in `Internal/OfficeLegacySingleByteEncoding.cs` uses the
`MBTABLE 256` decoding data from [Microsoft's Windows-1257 mapping hosted by Unicode](https://www.unicode.org/Public/MAPPINGS/VENDORS/MICSFT/WindowsBestFit/bestfit1257.txt).
The source SHA-256 is `B8C5D7F3B8C25C3D5625D44DD3D6EE7A06E652DDF77373D050282C1CB7517366`.
Encoding uses exact reverse matches; the source's `WCTABLE` best-fit aliases are not used.
The Unicode License V3 copyright and permission notice is retained in
`Licenses/Unicode-LICENSE.txt`. This data introduces no runtime encoding provider dependency.

## Adobe Core 14 font metrics

`Fonts/OfficeStandardFontMetrics.Data.cs` holds advance widths generated by
`Build/Generate-PdfStandardFontWidths.py` from Adobe's Core 14 AFM files (AFM 4.1).
The Adobe copyright notices are retained in the generated file, and the permission notice
that accompanies the AFM files is in `Licenses/Adobe-Core14-AFM-LICENSE.txt` (SPDX `APAFML`).
The metrics were reduced to advance widths keyed by Unicode; no AFM file is redistributed.

## AV1 reference data

The managed AVIF decoder implements a bounded AV1 still-image subset. The generated default
probability tables (`Raster/Avif/*.Cdfs*.cs`) are checked against hash-pinned AOM v3.13.1 numeric
data; the quantizer and intra-prediction tables (`Raster/Avif/*.Generated.cs` and
`Raster/Avif/OfficeAv1QuantizerMatrices.bin`) are generated from the AV1 1.0.0 Errata 1
specification. The AOM BSD-2-Clause license and the AOMedia patent license are retained in
`Licenses/aom-LICENSE.txt` and `Licenses/aom-PATENTS.txt`.

Fixture generators under `OfficeIMO.Drawing.Tests/TestAssets/Avif` use isolated native AOM,
libavif and dav1d reference tools. They are opt-in test tooling and are not part of this package.

## WebM VP8 reference data

The managed VP8 decoder follows RFC 6386. Its probability and quantizer tables in
`Raster/Webp/OfficeVp8Tables.cs` are the values specified there and were checked against the
WebM libwebp reference. The WebM BSD-3-Clause license and patent grant are retained in
`Licenses/libvpx-LICENSE.txt` and `Licenses/libvpx-PATENTS.txt`. No libwebp or libvpx runtime
dependency is introduced.

## ImagePlayground HEIF container metadata
