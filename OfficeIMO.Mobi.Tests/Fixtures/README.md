Calibre 9.19.0 wrote all four Harbour Signal fixtures from the same original
EPUB. The versions are standalone MOBI, PalmDOC PDB, standalone AZW3, and a
MOBI with both legacy and KF8 sections. The source uses a cover, one inline
image, contents and a link between two sections.

`harbour-empty-style.azw3` starts from the Calibre AZW3. The opening chapter
includes whitespace-only and self-closing styles, SVG CDATA, links to two empty styles
and an empty emphasis element before a UTF-8 text link target. The modified
ranges keep their original lengths and Kindle fragment offsets. The text
record is stored uncompressed.
