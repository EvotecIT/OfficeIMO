# Independent invoice fixtures

These unmodified CII and UBL examples come from the KoSIT XRechnung test suite,
release `v2026-08-31`, under the accompanying Apache 2.0 license.

Source: https://github.com/itplr-kosit/xrechnung-testsuite/tree/v2026-08-31/src/test/business-cases/standard

The fixtures exercise native parsing, declared totals, identifier and reference
mapping, and conversion independently of OfficeIMO's writers.
