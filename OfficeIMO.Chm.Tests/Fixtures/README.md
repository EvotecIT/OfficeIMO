# CHM fixtures

`svnbook-ms-htmlhelp.chm` is the unchanged Microsoft HTML Help compilation of *Version Control with Subversion*, obtained from Apache Tika's `testChm3.chm` parser fixture:

- [Pinned source file](https://github.com/apache/tika/blob/dc571dddba324485fdb6dc1d665163e56267d0fc/tika-parsers/tika-parsers-standard/tika-parsers-standard-modules/tika-parser-microsoft-module/src/test/resources/test-documents/testChm3.chm)
- SHA-256: `6fef835e8822a46642eedfc61f0821aed4a4cbc5d59dca9b641b4bc5a409f94d`
- Copyright 2002–2008 Ben Collins-Sussman, Brian W. Fitzpatrick, and C. Michael Pilato.
- [Creative Commons Attribution 2.0](https://creativecommons.org/licenses/by/2.0/). The archive contains the complete license in `/apd.html`; `/index.html` also carries attribution. See [the authors' book](https://svnbook.red-bean.com/en/1.6/svn-book.html).

The fixture has 181 HTML topics and 226 directory entries. `svnbook-ms-htmlhelp.sha256.tsv` contains entry length, lowercase SHA-256 and original CHM path, including directories and internal streams. It was generated by independently extracting all entries with [CHMLib at revision 2bef8d063ec7d88a8de6fd9f0513ea42ac0fa21f](https://github.com/jedwing/CHMLib/tree/2bef8d063ec7d88a8de6fd9f0513ea42ac0fa21f), using `chm_enumerate(..., CHM_ENUMERATE_ALL, ...)` and `chm_retrieve_object()`. The product contains no CHMLib source or binary. The test compares every decoded entry against this manifest rather than relying on a self-round-trip.

`ChmFixture` builds small, test-only uncompressed ITSF 2/3 archives for deterministic navigation, text encoding, link, resource, limit and ownership contracts. It does not produce compressed qualification evidence.
